# Designer Render Compare

This developer tool compares the image exported by the frontend designer with the image generated by the backend Puppeteer renderer from the same normalized JSON.

## Enable the Tool

Add this query parameter to the designer URL:

```text
renderCompare=true
```

Example:

```text
http://localhost:4900/certificate-designer?edit=true&id=75&dt=true&designCode=DCTeae9879a-3709-4b05-a619-08d06d6f71fb&ru=dGVzdGFwcC50aGVzb2xvLm5ldHdvcms=&renderCompare=true
```

When enabled, the top action bar shows a `Compare API Render` button.

## Use a Local Backend

By default, the tool uses the local `Solo_Cron_API` renderer:

```text
http://localhost:3000
```

To compare against a different `Solo_Cron_API` server, add `renderApiBase`:

```text
renderApiBase=http://localhost:3000
```

Full local example:

```text
http://localhost:4900/certificate-designer?edit=true&id=75&dt=true&designCode=DCTeae9879a-3709-4b05-a619-08d06d6f71fb&ru=dGVzdGFwcC50aGVzb2xvLm5ldHdvcms=&renderCompare=true&renderApiBase=http://localhost:3000
```

Do not include `/api` for the local cron API. The renderer endpoint is mounted directly under `/puppeter-canvas`.

## What It Does

1. Exports the current frontend canvas as a PNG using the same crop, retina scaling, and workarea logic as preview/save.
2. Builds the normalized JSON payload that is stored for backend rendering.
3. Sends that JSON to `/puppeter-canvas/json-to-image` or `/puppeter-canvas/json-to-badgeImage`.
4. Converts the backend PNG buffer response into an image.
5. Compares frontend and backend images pixel-by-pixel.
6. Shows frontend image, API image, diff image, dimensions, visible pixel difference, strict pixel difference, and max channel delta.

## Reading Results

- `Dimensions` must match for a valid exact comparison.
- `visible pixels` uses a small channel threshold to ignore tiny anti-aliasing noise.
- `strict pixels` counts any channel difference at all.
- The diff image marks visible differences in red.

For exact parity, dimensions should match and visible pixel differences should be zero or near zero.
